# Supplementary tables and 84% confidence intervals

This repository contains the supplementary Excel tables associated with the article “Kinship networks, kinlessness and friendship at different ages. An extensive analysis of the Italian case over a 20–year period”.

It includes seven Excel workbooks, corresponding to Figures 1–7, with results organized by year (1998 and 2016), sex (males, females, and the total population), age group, and kinship category, where applicable.

The files report the estimates presented in the Supplementary Material together with their 84% confidence intervals. This repository is intended to support the transparency, reproducibility, and verification of the reported results.
